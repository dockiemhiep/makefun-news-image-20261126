# The World in One Picture — 26 Nov 2026

This repository is an entry to the make.fun bounty at https://make.fun/bounty/news-image-20261126. Its program copies a one-page newspaper image summing up the world news of Thursday 26 November 2026 (the US proposing new tariffs on 14 trading partners, the Houthis claiming a hit on Saudi Arabia's Ras Tanura refinery as Brent tops $94, Ukraine saying it struck a Russian air base, and the Nasdaq sinking nearly 4% on AI fears) to the output directory.

## Run it

```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
